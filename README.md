# StartWizard

## What is it?
StartWizard is a custom windows start menu. StartWizard intercepts the windows key presses, and then displays the menu on your display.

## What can it do?
1. Open apps
2. Show open windows by app
3. Run calculations
4. It looks pretty

## To "Install":
1. Unpack the release file
2. Put the unpacked folder _somewhere_
3. Create a shortcut to startwizard.exe
4. Place the shortcut file in `shell:startup`, a folder you can find in Windows
5. Startwizard will now start when your computer is started.
6. To see if StartWizard is running you can check your taskbar's system tray
7. Either run the exe manually or restart your pc to start StartWizard
